# interaction

Create and configure gameplay interaction surfaces on Blueprints and placed actors — interactable interfaces, interaction components, trace settings, prompt widgets, destruction health state, and simple door/chest/switch/loot/save interaction properties. Use this when the target is an interactable Blueprint asset or a specific placed actor; it does not replace `call("ui")` or `call("widget")` for authoring the prompt Widget Blueprints themselves.
